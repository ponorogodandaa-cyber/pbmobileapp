Pasang userscript

1. Pasang ekstensi Tampermonkey di Chrome PC.
2. Dashboard → Utilities → Add a new script.
3. Hapus kode bawaan, paste file `.user.js` hasil download.
4. Simpan dengan Ctrl+S.
5. Buka match `https://pbmobile.ch/jogo?...`.
6. Klik sekali di game. F2 bidik, F3 ESP, F4 kepala/tubuh.
Kalau muncul tulisan `BLAZE LICENSE: AKTIF`, berarti lisensi tersambung. Key hanya bisa dipakai di 1 device pertama yang aktif.
